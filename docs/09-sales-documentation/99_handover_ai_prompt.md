# CẨM NANG CHUYỂN GIAO & PROMPT GỢI Ý CHO AI MỚI (AI HANDOVER PROMPT)

Tài liệu này cung cấp ngữ cảnh toàn diện và các câu lệnh (Prompts) được thiết kế sẵn để bạn sao chép và dán trực tiếp vào một công cụ AI khác (như Claude 3.5 Sonnet, ChatGPT-4o...) nhằm tiếp tục biên tập, làm đẹp hoặc mở rộng bộ tài liệu bán hàng Taviweb.

---

## 1. CÂU LỆNH CHUYỂN GIAO TOÀN DIỆN (MASTER PROMPT)
*Hãy sao chép toàn bộ nội dung dưới đây và gửi cho AI mới để bắt đầu phiên làm việc:*

```markdown
Bạn là một Chuyên gia Tư vấn Chiến lược Kinh doanh, Nhà thiết kế Tài liệu và Copywriter cao cấp chuyên ngành SaaS & Chuyển đổi số. Tôi đang xây dựng một bộ tài liệu bán hàng cho giải pháp TAVIWEB (nền tảng tạo Website tức thì tích hợp CRM, AI Chatbot chốt số và Booking cho các doanh nghiệp địa phương như Spa, Nha khoa, Luật sư, Phòng khám...).

Tôi đã có 4 file bản thảo dạng Markdown (.md) thô dưới đây, có nằm trong project này:
1. File 1: "01_sales_playbook_internal.md" (Cẩm nang đào tạo Sales nội bộ)
2. File 2: "02_solution_proposal_client.md" (Đề xuất giải pháp gửi Khách hàng)
3. File 3: "03_features_admin_guide.md" (Hướng dẫn tính năng trang quản trị Admin)
4. File 4: "04_detailed_features_description.md" (Mô tả chi tiết các phân hệ chức năng)

MỤC TIÊU CỦA BẠN:
Giúp tôi phát triển, hoàn thiện câu từ, cấu trúc lại định dạng và làm đẹp bộ tài liệu này để sẵn sàng xuất bản thành file PDF hoặc Word (DOCX) chuyên nghiệp nhất.

HÃY TUÂN THỦ CÁC NGUYÊN TẮC SAU:
1. Phong cách ngôn ngữ: Chuyên nghiệp, sắc bén, định lượng bằng số liệu cụ thể (như quy đổi thời gian lãng phí, so sánh chi phí lũy kế 3 năm). Tránh dùng các từ ngữ sáo rỗng, tập trung vào giá trị tài chính và lợi nhuận (ROI) cho khách hàng.
2. Thiết kế tài liệu: Bổ sung các chỉ dẫn thiết kế trực quan (Ví dụ: [Chèn ảnh chụp màn hình Admin tại đây], [Callout Box nhấn mạnh], [Bảng so sánh làm nổi bật cột Pro]).
3. Cải tiến nội dung: Làm mịn các kịch bản tư vấn của Sales và kịch bản chốt số điện thoại của AI Chatbot sao cho tự nhiên và có tỷ lệ chuyển đổi cao nhất.

Hãy phản hồi xác nhận rằng bạn đã hiểu rõ bối cảnh và sẵn sàng sử dụng nội dung của từng file để bắt đầu xử lý.
```

## 2. QUY TRÌNH CHUYỂN GIAO TỪNG PHẦN

Sau khi AI mới xác nhận đã hiểu Master Prompt ở trên, bạn hãy lần lượt sao chép nội dung của từng file gửi cho AI đó theo thứ tự dưới đây kèm chỉ thị cụ thể:

### 📥 Bước 1: Gửi nội dung File 1 (Playbook Sales nội bộ)
*   **Prompt gửi kèm**:
    ```markdown
    Dưới đây là nội dung của File 1: "01_sales_playbook_internal.md". Hãy đọc, viết lại câu từ cho trôi chảy, tối ưu hóa các kịch bản gọi điện tư vấn và kịch bản xử lý từ chối cho Sales. Đề xuất thêm các mẹo tâm lý khách hàng để nhân viên chốt sale dễ dàng hơn.
    
    [DÁN NỘI DUNG FILE 01_sales_playbook_internal.md VÀO ĐÂY]
    ```

### 📥 Bước 2: Gửi nội dung File 2 (Đề xuất giải pháp cho Khách hàng)
*   **Prompt gửi kèm**:
    ```markdown
    Dưới đây là nội dung của File 2: "02_solution_proposal_client.md". Tài liệu này sẽ gửi trực tiếp cho chủ doanh nghiệp. Hãy viết lại theo văn phong cực kỳ trang trọng, mang tính thuyết phục cao. Định dạng lại bảng so sánh chi phí 3 năm và bổ sung thêm các hộp thông tin (Callout boxes) để làm nổi bật các phần "Chi phí ẩn của việc làm thủ công" và "Cam kết sở hữu mã nguồn của Taviweb".
    
    [DÁN NỘI DUNG FILE 02_solution_proposal_client.md VÀO ĐÂY]
    ```

### 📥 Bước 3: Gửi nội dung File 3 (Hướng dẫn sử dụng Admin)
*   **Prompt gửi kèm**:
    ```markdown
    Dưới đây là nội dung của File 3: "03_features_admin_guide.md". Hãy chuyển đổi tài liệu hướng dẫn kỹ thuật này thành một cuốn cẩm nang "Quick Start Guide" sinh động, dễ hiểu cho người không chuyên về công nghệ. Thêm các ghi chú gợi ý vị trí đặt hình ảnh minh họa giao diện (ví dụ: màn hình Calendar đặt lịch, màn hình cấu hình file PDF cho AI học RAG).
    
    [DÁN NỘI DUNG FILE 03_features_admin_guide.md VÀO ĐÂY]
    ```

### 📥 Bước 4: Gửi nội dung File 4 (Mô tả chi tiết phân hệ chức năng)
*   **Prompt gửi kèm**:
    ```markdown

Hãy viết lại với giọng điệu sắc bén, bổ sung thêm các hình ảnh phác thảo trực quan hoặc hộp Callout ghi chú và so sánh tính năng giữa các phân khúc khách hàng để sale dễ thuyết phục đối tác.
